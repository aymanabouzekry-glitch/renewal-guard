# Changelog — RenewalGuard (Exclusive Source-Code Sale Edition)

## [1.0.0] — October 2026
### Added
- **Core Platform:** Next.js 16.4.0 App Router architecture with Drizzle ORM and PostgreSQL.
- **Authentication & Security:** NextAuth session management, server-side API authorization guards (`src/server/security/audit-auth.ts`), and immutable security audit logging (`audit_events`).
- **Document Registry:** Full CRUD operations, search, pagination, D-30 warning calculations, and rule-based Readiness Score (0–100).
- **Calendar & Executive Reports:** Dedicated `/reports` view with category breakdown, financial cost exposure, and timeline filtering.
- **Data Portability:** CSV export, downloadable CSV template, and validated CSV import with row-level error preview dialog.
- **White-Labeling & Onboarding:** Dynamic organization branding (App Name, Primary Color, Contact Email) and one-click guided sample workspace loader.
- **Internationalization (i18n):** Complete Arabic (RTL) and English (LTR) support with persistent locale switching.
